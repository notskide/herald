Herald
A fast, smart Discord bot built with Python.

Features:
• AI Processing powered by Google Generative AI for intelligent responses.
• Natural Voice using edge-tts for fast text-to-speech generation.
• Asynchronous performance built on discord.py and aiohttp.

Requirements:
• discord.py
• google-generativeai
• edge-tts
• aiohttp

Deployment:
Herald is designed to be easily hosted on cloud platforms like Render for 24/7 uptime. Just install the dependencies from requirements.txt and run herald.py.
